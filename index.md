# OpenBeta

The OpenBeta project is an attempt to make early Minecraft something the community has full control over.

## Projects

Here's a list of a few projects that belong to the grander OpenBeta Project.

| Name                                                               | Description                                                        |
| ------------------------------------------------------------------ | ------------------------------------------------------------------ |
| [Technical Beta Wiki](https://pixelbrush.dev/beta-wiki/)           | A Wiki that describes the Beta 1.7.3 Internals                     |
| [Betrock++](https://github.com/OfficialPixelBrush/BetrockPlusPlus) | A Beta 1.7.3 Server and Client written largely from scratch in C++ |
| [LibreProg](https://pixelbrush.dev/LibreProg/)                     | Notchian-like, fully open Programmer Art                           |

## Tools / Toy Projects

These are smaller mini-projects that, while still part of OpenBeta, aren't necessarily part of it's grander vision, or are just not as important for most people.

| Name                                                                   | Description                                                                                                         |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| [GoldenBase](https://pixelbrush.dev/GoldenBase/)                       | A pre-release Minecraft seed explorer                                                                               |
| [BPPT](https://github.com/OfficialPixelBrush/BetaPacketPlainTextifier) | Turns Wireshark network captures into Markdown tables that make decoding Beta 1.7.3 Network activity easier to read |
| [BetaAuth](https://github.com/OfficialPixelBrush/BetaAuth)             | Fully independent Beta Server authentication                                                                        |
