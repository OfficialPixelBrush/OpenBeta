OpenBeta

Discord Source

The OpenBeta project is an attempt to make early Minecraft something the community has full control over. This is being done through reverse engineering, reimplementing and documenting the ins and outs of how old Minecraft worked.

Projects

Here's a list of a few projects that belong to the grander OpenBeta Project.

Technical Beta Wiki Betrock++ LibreProg
Wiki that describes the Beta 1.7.3 "specification" Beta 1.7.3-compatible Server and (eventually) Client written largely from scratch in C++ Notchian/Programmer Art-like textures and assets

Tools / Toy Projects
